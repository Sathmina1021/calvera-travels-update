# Calvera Travels Website 🌍

## 🚀 Description
Calvera Travels is a modern, responsive travel agency website designed to showcase tour packages, destinations, and services. The website helps users explore travel options and easily connect with the agency for bookings and inquiries.

## 🧰 Tech Stack
- Frontend: HTML, CSS, JavaScript, React.js
- Backend: Node.js, Express.js
- Database: MongoDB

## ✨ Features
- Responsive and user-friendly design
- Tour package listing and details
- Contact and inquiry form
- Modern UI for travel agency branding
